# Screenshots go here

Add screenshots of your Bob 2.0 task sessions to this folder before
submitting the hackathon entry. Suggested set, one image each:

1. Bob's initial plan/task breakdown after receiving the master prompt.
2. A parallel-tasks view showing scanner/security/refactor/test/report
   subagents running.
3. The moment a bug was caught by running the tool (e.g. the
   `mysql_query()` literal-argument fix, or the CSRF regex fix) — the
   run-observe-fix loop is the strongest evidence of Agent mode actually
   being used, not just prompted once.
4. The final `legacylift run` output showing verification PASSED.
5. Bob's own session summary / task completion screen, if the client
   shows one.

Name them descriptively, e.g. `01-initial-plan.png`, `02-parallel-tasks.png`,
`03-bug-caught-live.png`, `04-pipeline-passed.png`. Reference them from
`session-log.md` by filename once added.
